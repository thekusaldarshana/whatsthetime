# Security Policy

## Supported versions

Only the code deployed at https://whatsthetime.top (the `main` branch) is supported.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through
[GitHub security advisories](https://github.com/thekusaldarshana/whatsthetime/security/advisories/new),
or by email to thekusaldarshana@gmail.com.

Include the affected URL or file, the steps to reproduce, and the impact you believe it has.
You can expect an initial response within a few days.

The site is a static, read-only front end with no user accounts or stored personal data, so
please focus reports on issues such as cross-site scripting, dependency vulnerabilities that
are reachable in the built output, or unsafe third-party scripts.
